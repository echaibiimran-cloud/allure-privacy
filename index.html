Politique de confidentialité

Dernière mise à jour : mai 2025

Allure (« l'Application ») est une application de coaching à la course à pied. Cette politique explique quelles données nous collectons, comment nous les utilisons et quels sont vos droits.

1. Données collectées

  • Données de profil : prénom, sexe, date de naissance, poids, taille, objectif de course. Ces données sont stockées localement sur votre appareil.
  • Données de course : GPS, distance, durée, allure, dénivelé. Stockées localement sur votre appareil.
  • Compte communauté (optionnel) : adresse e-mail, nom d'utilisateur. Stockés sur nos serveurs Supabase si vous créez un compte.
  • Données partagées (optionnel) : résumés de courses publiés sur le fil communautaire.

2. Utilisation des données

  • Générer des plans d'entraînement personnalisés via l'IA (les données sont envoyées de façon anonymisée à l'API Anthropic).
  • Afficher votre historique et vos statistiques.
  • Permettre les fonctionnalités sociales si vous y participez.

3. Partage des données

Nous ne vendons jamais vos données. Elles peuvent être transmises à :

  • Anthropic (analyse IA) — données anonymisées, sans nom ni identifiant.
  • Supabase (infrastructure) — uniquement si vous créez un compte.

4. Localisation

L'accès au GPS est demandé uniquement pendant une course active. Les données de localisation ne sont jamais transmises à des tiers.

5. Conservation des données

Les données locales restent sur votre appareil jusqu'à la suppression de l'application. Les données de compte peuvent être supprimées sur demande.

6. Vos droits

Vous pouvez demander l'accès, la correction ou la suppression de vos données en nous contactant.

7. Contact

Pour toute question : contact@allure-app.fr
